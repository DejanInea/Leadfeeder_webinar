# Leadfeeder webinar

[Open the webinar transcript and report](https://DejanInea.github.io/Leadfeeder_webinar/)

The website entry point is `index.html`, which opens
`Webinar - Full speaker-labeled transcript.html`.

GitHub Pages publishes the root directory of the `main` branch.

To rebuild the bilingual page after editing its template, theme, or translations:

```sh
python build_webinar_page.py
```

The downloaded video, local editor settings, caches, and working reference
captures are excluded from Git.
